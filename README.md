# windows-reinstall-backup

Simple PowerShell scripts to back up and restore user data before/after Windows reinstall.

اسکریپت‌های سادهٔ PowerShell برای بکاپ و بازیابی داده‌های کاربر قبل و بعد از نصب مجدد ویندوز.

## Usage / نحوه استفاده
- Backup: run `Run-Backup.bat`
- Restore: run `Run-Restore.bat`

- بکاپ: اجرای `Run-Backup.bat`
- بازیابی: اجرای `Run-Restore.bat`
